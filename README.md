# Transaction Ledger Service

A Java and Spring Boot REST API for modeling financial accounts and processing transfers between them.

## Version 1

The first version of the project will support:

* Creating financial accounts
* Retrieving account information
* Transferring funds between accounts
* Persisting account and transfer data in PostgreSQL
* Validating basic transfer rules
* Ensuring a transfer either completes fully or makes no changes

## Tech Stack

* Java 21
* Spring Boot
* Gradle
* PostgreSQL

## Project Status

Version 1 is currently under development.
